# Game
This is a snake game.
<br>
Creator - Nandini Gupta
<br>
step 1:
 Setup the screen. 
<br>
step 2:
 Create the snake head, define functions for its movement and assign keys for the on click movement.
<br>
step 3:  
Create snake food and design its random positioning after collision with the head.
<br>
step 4:
Create the snake body and append it with the head as head collides with the food.
<br>
step 5:
Create check for collisions with the border and adjust snake body accordingly after collisions.
<br>
step 6:
Create check for collision with the body and adjust snake body accordingly after collision.
<br>
step 7:
Create the scoring system and maintain the high score, also add the speed increase and resetting it when game is over.
<br>
Finally a beginner friendly snake game is created.
